## 📖 Sobre

O **exemplo-express** é um exemplo de **API GET** desenvolvida com **Node.js** e **Express**, criado para **praticar a criação de rotas e requisições HTTP**.

## ✨ Objetivos

- 🛣️ Praticar a criação de rotas
- 🌐 Entender como funcionam as requisições HTTP
- 🚂 Conhecer o framework Express na prática
- 🟢 Estudar o desenvolvimento de APIs com Node.js
